# Timer

The Timer app allows you to set countdown timers with presets for Pomodoro sessions.

## Features

- Custom time setting (hours, minutes, seconds)
- Start, pause, reset controls
- Preset timers for Pomodoro (25:00) and breaks (5:00, 10:00)
- Visual and audio alerts when time is up

## Usage

1. Set the time using the input fields or select a preset.
2. Click "Set" to configure the timer.
3. Click "Start" to begin the countdown.
4. Use "Pause" and "Reset" as needed.

## Dependencies

- Local storage for timer state
