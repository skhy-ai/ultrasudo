# Weather App

The Weather App provides current weather information and forecasts using external APIs.

## Features

- Current weather display with temperature, humidity, wind speed
- Hourly and daily forecasts
- Search by city name
- Weather icons and descriptions
- Responsive design with Tailwind CSS

## Usage

1. Allow location access or search for a city.
2. View current weather and forecasts.
3. Check hourly and daily predictions.

## Dependencies

- Weather API (e.g., OpenWeatherMap)
- Tailwind CSS for styling
- Geolocation API for location
