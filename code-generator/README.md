# Code Generator

The Code Generator app allows you to generate code using AI providers like OpenAI, Gemini, or LMStudio.

## Features

- Multi-provider support (OpenAI, Gemini, LMStudio)
- Staged flow: Prompt → Testcases → Validate → Generate
- API key management via API Key Manager
- Test case generation and validation
- Code generation for various languages

## Usage

1. Select a provider and model.
2. Enter a prompt describing the code you want.
3. Generate test cases.
4. Accept test cases.
5. Generate the code file.

## Dependencies

- OpenAI API or Gemini API for online providers
- LMStudio for local generation
- Font Awesome for icons
