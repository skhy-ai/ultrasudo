# API Key Manager

The API Key Manager app allows you to centrally manage API keys for various services like OpenAI, Gemini, LMStudio, and Alpha Vantage.

## Features

- Secure storage of API keys in local storage
- Support for multiple providers: OpenAI, Gemini, LMStudio, Alpha Vantage
- Test API connections
- Easy key management for other apps

## Usage

1. Enter API keys for each provider.
2. Save the keys.
3. Test the connection if needed.
4. Keys are used by other apps via the DataManager.

## Dependencies

- Local storage for key storage
- Provider APIs for testing
