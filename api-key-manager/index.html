How to get your OpenRouter key
  1. Visit openrouter.ai and click Sign In
  2. After signing in, go to openrouter.ai/keys
  3. Click Create Key — give it a name like "Ultrasudo"
  4. Copy the key (starts with sk-or-v1-) and paste it above
  5. The free tier includes access to Google Gemini Flash and other free models

Google Gemini Free Tier

Google's multimodal AI. Gemini Flash is free with generous limits.

Get free key
How to get your Gemini key
  1. Go to Google AI Studio — sign in with your Google account
  2. Click Get API Key in the left sidebar
  3. Select Create API key in new project
  4. Copy the key (starts with AIza) and paste it above
  5. The free tier includes Gemini 1.5 Flash & 2.0 Flash with 15 requests/min

OpenAI Paid

GPT-4o, GPT-4o-mini and more. Requires a paid plan or credits.

Get API key
How to get your OpenAI key
  1. Go to platform.openai.com and sign in or create an account
  2. Navigate to API Keys in the dashboard
  3. Click Create new secret key
  4. Copy the key (starts with sk-) — it's only shown once
  5. Add billing credits at Billing to make API calls

LM Studio Local

Run AI models locally on your machine — completely private and offline.

Download free
How to set up LM Studio
  1. Download LM Studio for your OS
  2. Open LM Studio and download a model (e.g. Llama 3.2 or Gemma 2)
  3. Go to Local Server tab and click Start Server
  4. The default port is 1234 — no API key needed
  5. Click Test Connection to verify Ultrasudo can reach LM Studio
