# Notebook

The Notebook app is a rich text editor for creating and editing documents with formatting options.

## Features

- Rich text editing with formatting (bold, italic, headings, etc.)
- Font family and size selection
- Undo/redo functionality
- Document title management
- Local storage for documents

## Usage

1. Enter a document title.
2. Use the toolbar to format text (headings, bold, etc.).
3. Edit the content in the editor area.
4. Save or open documents using the top bar buttons.

## Dependencies

- Font Awesome for icons
- Local storage for saving documents
